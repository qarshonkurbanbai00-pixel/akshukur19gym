# АҚШҰҚЫР — ЦИФРЛЫҚ ШЕЖІРЕ

Ақшұқыр ауылының (Маңғыстау облысы, Түпқараған ауданы) тарихын зерттеуге арналған
интерактивті цифрлық жоба-сайт. Мектептегі ғылыми-шығармашылық конкурсқа арналған.

---

## 1. Іске қосу (Windows)

### Талаптар
- **Python 3.10+** орнатылған болуы керек: https://www.python.org/downloads/
  (орнату кезінде **«Add Python to PATH»** белгісін қоюды ұмытпаңыз)

### Қадамдар
1. Жоба папкасын кез келген жерге ашыңыз (ZIP-тен шығарыңыз).
2. Папка ішінде терезе ашып, командалық жолды (cmd) іске қосыңыз
   немесе жай ғана **`run.bat`** файлын екі рет басыңыз.
3. Командалық жолда:
   ```bat
   pip install -r requirements.txt
   python app.py
   ```
4. Браузерден ашыңыз: **http://127.0.0.1:5000**

### Тоқтату
Командалық жолда `Ctrl + C` басыңыз.

## 2. Жоба құрылымы

```
akshukur-digital-chronicle/
├── app.py                  # Flask сервері (барлық route + JSON API)
├── requirements.txt        # Тәуелділіктер
├── run.bat                 # Windows үшін жылдам іске қосу
├── data/                   # БАРЛЫҚ КОНТЕНТ ОСЫНДА (JSON)
│   ├── history.json        # Тарихи кезеңдер (timeline)
│   ├── places.json         # Карта нүктелері + экскурсия маршруты
│   ├── sources.json        # Дереккөздер / цифрлық архив
│   └── interviews.json     # Ауызша тарих сұхбаттары
├── templates/              # HTML беттер
├── static/
│   ├── css/style.css       # Барлық стиль
│   ├── js/                 # main.js, map.js, timeline.js, 3d.js
│   ├── images/             # Фотолар ОСЫНДА салынады
│   └── models/             # GLB 3D модель ОСЫНДА салынады
└── screenshots/            # Конкурсқа арналған скриншоттар
```

## 3. НАҚТЫ МАТЕРИАЛДАРДЫ ҚАЙДА ҚОЮ КЕРЕК (өте маңызды)

| Материал | Қайда салу керек | Қосымша әрекет |
|---|---|---|
| **Фотолар** (тарихи/қазіргі) | `static/images/` | `data/*.json` ішіндегі `"image": null` орнына `"static/images/sizdin-foto.jpg"` деп жазыңыз |
| **«Кеше және бүгін» фотолары** | `static/images/before.jpg`, `static/images/after.jpg` | `templates/index.html` ішінде «Кеше және бүгін» бөліміндегі placeholder-ді ауыстырыңыз |
| **Аудио/видео сұхбаттар** | `static/media/` папкасын жасап, салыңыз | `data/interviews.json` ішіндегі `"media": null` орнына жол жазыңыз |
| **3D GLB модель** | `static/models/mashyryq.glb` | Файл осындай атпен салынса, 3D viewer оны **автоматты жүктейді** (placeholder модельдің орнына) |
| **Тарихи құжат сканері** | `static/images/archive/` | `data/sources.json` ішінде `"file"` өрісіне жол жазыңыз |
| **Архив сілтемесі (1887 дерегі)** | — | `data/sources.json` ішіндегі `src-1887-medrese` жазбасының `"source_reference"` өрісін нақты архив деректемесімен толтырыңыз |
| **Координаталары белгісіз нүктелер** | — | `data/places.json` ішінде `"lat": null, "lng": null` орындарына нақты координата жазыңыз — маркер картада автоматты пайда болады |

### JSON өңдеу ережесі
- Мәтіндерді тіркешек ішінде ғана өзгертіңіз.
- Өзгерістен кейін серверді қайта іске қосыңыз (`Ctrl+C`, содан кейін `python app.py`).
- `"evidence"` өрісі мына мәндердің бірі болуы керек:
  `written` 🟢 | `archive` 🔵 | `oral` 🟡 | `research` 🟠 | `reconstruction` 🟣 | `needs_data` ⚪

## 4. Деректер дәлелдеме деңгейлері

Жобада ешқандай тарихи факті ойдан шығарылмаған. Әр мәлімет мына деңгейлермен белгіленген:

- 🟢 **Жазба дерек** — жазба көздерде расталған
- 🔵 **Архив дерегі** — архив құжаттарына сілтеме
- 🟡 **Ауызша дерек** — жергілікті адамдардың естелігі (нақты тексеруді қажет етеді)
- 🟠 **Зерттеу материалы** — ашық зерттеулер/құжаттама
- 🟣 **3D реконструкция** — болжамды көрініс, тарихи факті ЕМЕС
- ⚪ **Дерек қажет** — әлі расталмаған, зерттеу барысында толықтырылады

---

## 5. Интернет қосылымы туралы

- Сайттың негізгі интерфейсі, мәтіндер, стильдер мен timeline **интернетсіз** жұмыс істейді.
- **Интерактивті карта (Leaflet)** мен **3D viewer (Three.js)** CDN-нен жүктеледі.
  Интернет болмаса, сол бөлімдерде «CDN жүктелмеді» деген түсіндірме көрсетіледі —
  сайттың қалған бөлігі бұзылмайды.
- Карта интернетсіз ортада тайлдары жүктелмейді, бірақ нүктелер тізімі көрсетіліп тұрады.

---

## 6. Конкурсқа ұсынуға кеңес

1. Сайтты іске қосып, негізгі беттердің скриншоттарын `screenshots/` папкасына салыңыз.
2. Нағыз құндылық — `data/` ішіндегі JSON файлдарды **нақты зерттеу деректерімен**
   (архив сілтемелері, сұхбат транскрипттері, сканерленген құжаттар) толтыру.
   Платформа бұған толық дайын: ешбір кодты өзгертпей-ақ контент ауыстырылады.
