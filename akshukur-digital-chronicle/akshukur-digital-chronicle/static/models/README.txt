3D МОДЕЛЬДЕР ПАПКАСЫ
=====================

Осы папкаға нақты 3D модельді мына атпен салыңыз:

    mashyryq.glb

Файл салынғаннан кейін /rekonstrukciya бетіндегі 3D viewer
оны АВТОМАТТЫ түрде жүктейді (placeholder модельдің орнына).

Талаптар:
- Формат: .glb (GLTF 2.0 binary)
- Үлкен файл болса, жүктелуі баяулауы мүмкін — 20-30 МБ-тан аспағаны жөн.

Модель жасау жолдары:
1. Blender-де модельдеп, File -> Export -> glTF 2.0 (.glb)
2. Фотограмметрия (Polycam, RealityCapture) арқылы нақты нысаннан сканерлеу
3. Sketchfab-тан лицензиясы рұқсат ететін модель жүктеп, GLB-ге конвертациялау

МАҢЫЗДЫ: модель сақталған нақты ғимарат ретінде емес,
«Тарихи деректерге сүйенген болжамды көрініс» ретінде ғана ұсынылады.
